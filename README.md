# OFFROAD 4×4 v0.5 — 10 уровней

Играть: https://geodenix.github.io/Offroad/

Браузерная WebGL-демоверсия для iPhone, Android и ПК. В обновлении сохранены первые четыре уровня и добавлено ещё шесть:

5. Тёмный ельник (263 м) — узкие тропы и валуны.
6. Песчаный карьер (286 м) — песок и склоны.
7. Топкая низина (310 м) — болото и ограниченный ремонт.
8. Горный серпантин (335 м) — крутые уклоны и каменные ворота.
9. Затопленная просека (359 м) — броды и перегрев.
10. Хребет испытаний (377 м) — грязь, песок, вода и камни.

Прогресс сохраняется в браузере, данные версии 0.4 не сбрасываются. Следующие уровни открываются после прохождения предыдущих. Управление: газ, тормоз, поворот, 4×4/4×2, LOW, лебёдка, ремонт.

Размещение: GitHub Pages, ветка main, папка /(root). Сайт полностью статический, без внешних CDN.

Это браузерный прототип с упрощённой физикой поверхностей, а не Android APK или обновление Godot-проекта. Производительность на iPhone следует проверить на самом устройстве.
