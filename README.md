# OFFROAD 4×4 — браузерная игра v0.3

Игра про бездорожье для iPhone, Android и компьютеров: 4×4/4×2, понижающая передача, лебёдка, повреждения, перегрев, износ двигателя, ремонт и СТО.

## Как открыть игру на iPhone

Когда GitHub Pages активирован, откройте **https://geodenix.github.io/Offroad/** напрямую в Safari. Используйте горизонтальную ориентацию экрана. Кнопки управления рассчитаны на сенсорный ввод.

## Как включить GitHub Pages

1. Откройте **Settings → Pages** в этом репозитории: https://github.com/geodenix/Offroad/settings/pages
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите **Branch: main**, папка **/(root)**, нажмите **Save**.
4. Подождите завершения публикации. Затем откройте https://geodenix.github.io/Offroad/

Сайт полностью статический. Главный файл — **index.html**, без внешних CDN и сервера. В случае проблем с WebGL игра показывает диагностику на экране. Для проверки настоящей 3D-графики необходимо открыть страницу непосредственно в Safari, а не через просмотрщик файлов в приложении.

### Примечание

Это браузерная демоверсия с упрощённой физикой и без APK. Отдельный проект Godot предназначен для развития более полноценного 3D-симулятора.
