# OFFROAD 4×4 — v0.4 (четыре уровня)

Браузерная 3D-игра про бездорожье для iPhone, Android и ПК.

## Уровни
1. **Лесная дорога** — 135 м. Лёгкое начало, редкие лужи и камни.
2. **Разбитый просёлок** — 181 м. Колеи, грязь, ухабы и препятствия.
3. **Болотная тропа** — 223 м. Длинные грязевые участки, пригодятся 4×4, LOW и лебёдка.
4. **Каменный перевал** — 244 м. Подъёмы, неровная трасса и семь камней.

Уровни открываются по очереди после прохождения предыдущего. Пройденные уровни сохраняются в браузере (localStorage), пока браузер хранит данные сайта. Нажми **УРОВНИ**, чтобы выбрать доступную трассу.

## Как включить сайт
Зайди в [Settings → Pages](https://github.com/geodenix/Offroad/settings/pages), выбери **Deploy from a branch**, ветка **main**, папка **/(root)**, нажми Save.

Адрес после включения и завершения публикации: https://geodenix.github.io/Offroad/

На iPhone открывай сайт прямо в Safari, лучше в горизонтальной ориентации. Прямая загрузка HTML во встроенном просмотрщике ChatGPT может мешать WebGL.

## Технические ограничения
Это браузерная демоверсия на JavaScript и WebGL с упрощённой физикой. Реалистичная деформация грязи уровня SnowRunner пока не реализована. Godot-проект v0.3 отдельно и пока не обновлён до системы четырёх уровней.
